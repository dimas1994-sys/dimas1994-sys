# 2D Конструктор игр (C#)

Минимальный прототип конструктора 2D-игр на **ASP.NET Core (C#)**.

## Что реализовано

- Понятный интерфейс редактора (3 панели: ресурсы, визуальный скриптинг, шаблоны).
- Удобное добавление ресурсов (sprite/audio/tilemap/script).
- Базовый визуальный скриптинг (создание нод и вывод их на доску).
- Готовые шаблоны проектов (Platformer, Top-Down Shooter, Puzzle).

## Запуск

```bash
dotnet restore
dotnet run
```

Откройте URL из консоли (обычно `https://localhost:5001` или `http://localhost:5000`).
