# DX-Ball Web Clone

Небольшая браузерная игра в стиле DX-Ball / Breakout на чистом HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Управление

- Движение платформы: `←` `→`, `A` `D`, либо мышь.
- Старт / перезапуск после проигрыша: `Space`.

## Механики

- Счёт, жизни и уровни.
- Разная прочность некоторых блоков (2 удара).
- Переход на следующий уровень при уничтожении всех блоков.
- Проигрыш при потере всех жизней.
